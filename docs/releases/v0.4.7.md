# dqt v0.4.7 — Release Notes

_Released: 2026-05-12_

## Summary

Three targeted improvements from the v0.4.7 priority list: a new `dqt list-detectors` CLI command, three new smoke tests covering it, and deprecation warnings on the dead EventSource adapter classes.

## What's new

### Features

- **`dqt list-detectors`** — prints all registered detector slugs grouped by family, with their plain-English label from `STAT_SCALES`. `--group <name>` filters to a single family; `--plain` prints slugs only (one per line), suitable for scripting.

### Fixes

- **EventSource deprecation** — `AirflowEventSource`, `DagsterEventSource`, and `DbtCloudEventSource` now emit `DeprecationWarning` on instantiation. The causal discovery math (`granger_pairwise`, PCMCI+) does not use event sources; the parameter was removed in v0.4.3. These three classes will be removed in v0.6.0. `InMemoryEventSource` and `NullEventSource` are unaffected.

### Tests

- Three new smoke tests for `list-detectors`: plain output (≥60 slugs), `--group` filter correctness, `--help` exit.

## Breaking changes

None. The deprecation warnings are warnings, not errors.

## Upgrade

```bash
pip install --upgrade dqtlib
```

## What's next

Cloud adapter integration tests (Snowflake/BigQuery/Databricks/ClickHouse) require live credentials — nightly CI setup. NAB/Yahoo Webscope S5 benchmarks for all 64 detectors.

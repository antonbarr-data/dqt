# dqt v0.4.6 — Release Notes

_Released: 2026-05-12_

## Summary

Patch: dashboard footer version is now read dynamically from `dqt.__version__` instead of being hardcoded in the HTML template. No manual update needed on future releases.

## Fixes

- **Dynamic dashboard version** — `build_app()` now passes `dqt_version` into the index template context. The footer renders `dqt v{{ dqt_version }}` and the "what's new" link points to the releases index (`docs/releases/README.md`) rather than a version-specific URL.

## Upgrade

```bash
pip install --upgrade dqtlib
```

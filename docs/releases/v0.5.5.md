# dqt v0.5.5 — Release Notes

_Released: 2026-05-12_

## Summary

Statistical primer in docs and auto-generated README headline numbers from the benchmark
CSV. Running `scripts/update_readme_stats.py` keeps the README current without manual
edits each release.

## What's new

### `docs/statistical-primer.md`

A concise (5-page) guide to the statistical concepts behind dqt's detectors. Covers:

- How fit/score works and how to interpret the [0,1] score range
- All five detector families with recommended choices and common pitfalls
- A decision tree ("which detector should I use?")
- Score threshold interpretation and how `STAT_SCALES` maps scores to verdicts
- Statistical power guidance: minimum N per detector family
- Links to per-detector algorithm docs, benchmark results, and check YAML format

### `scripts/update_readme_stats.py`

Reads `examples/benchmarks/results.csv` and updates the `<!-- BENCHMARK_STATS_START -->`
block in `README.md` with live numbers:

```
**20 detectors** across 4 families · best F1 **0.933** (holt_winters, 30-trial
95% CI [0.933, 0.933]) · benchmarked on 8 synthetic scenarios
· [full results](examples/benchmarks/results.csv)
```

Run it manually after `benchmarks/run_benchmarks.py`, or add it to CI alongside the
benchmark job:

```bash
uv run python scripts/update_readme_stats.py
```

# dqt v0.4.8 — Release Notes

_Released: 2026-05-12_

## Summary

LLM Wiki synthesis pipeline: two new CLI commands that turn a folder of raw source
documents (semantic YAML, incident tickets, SQL, reports) into a structured AI-written
knowledge wiki, plus an HTML report generator.

## What's new

### Features

- **`dqt wiki sync <raw/> <wiki/>`** — reads all `.md`, `.yaml`, `.sql`, `.py`, `.html`
  files under `raw/`, groups them by top-level subfolder, and calls Anthropic Claude to
  write a concise knowledge article for each group. Only re-processes groups whose source
  content has changed since the last sync (hash-based cache in `wiki/.sync_manifest.json`).
  `--force` re-synthesises everything. `--model` selects the Anthropic model
  (default: `claude-opus-4-7`). Requires `ANTHROPIC_API_KEY` env var.

- **`dqt wiki status <raw/> <wiki/>`** — shows which source groups are up to date,
  pending first synthesis, or changed since last sync. Useful before a `sync` run.

- **`dqt report --vault <wiki/> --out <file.html>`** — generates a self-contained dark-mode
  HTML knowledge report from synthesised wiki entries. Matches the existing dqt report
  visual style (JetBrains Mono, sharp corners, dqt accent colour). No extra deps required.

- **New library module `dqt.wiki`** — `load_raw_documents`, `synthesize_entries`,
  `write_wiki`, `read_wiki_entries`, `load_manifest` — the full pipeline is importable
  for custom workflows.

- **Example `raw/` scaffold** under `examples/gigler/raw/` — four subfolders
  (`semantic/`, `tickets/`, `code/`, `reports/`) with realistic Gigler documents to
  demonstrate the workflow.

### Dependencies

- `anthropic>=0.26` added to `dqt-cli` core deps and available as `dqtlib[wiki]` for
  library-only usage.

### Tests

- 8 new smoke tests covering all wiki and report subcommands: help, missing-dir,
  empty-dir, and end-to-end HTML generation.

## Breaking changes

None.

## Upgrade

```bash
pip install --upgrade dqt-cli
# or for library-only usage:
pip install "dqtlib[wiki]>=0.4.8"
```

## Usage

```bash
# 1. Put your source docs under raw/
mkdir -p raw/semantic raw/tickets raw/code raw/reports

# 2. Synthesise wiki entries (needs ANTHROPIC_API_KEY)
export ANTHROPIC_API_KEY=sk-ant-...
dqt wiki sync raw/ wiki/

# 3. Check status at any time
dqt wiki status raw/ wiki/

# 4. Generate an HTML report
dqt report --vault wiki/ --out knowledge_report.html
```

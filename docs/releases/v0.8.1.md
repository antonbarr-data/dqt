# dqt v0.8.1 -- Release Notes

_Released: 2026-05-12_

## Summary

Active loose ends batch: dashboard CLI auth flags, generalized smoke tests for
every subcommand, and a README numbers update script.

## What's new

### `dqt dashboard --token TOKEN` / `--generate-token`
Pass a bearer token directly from the CLI. `--generate-token` prints a
cryptographically random 64-char hex token and starts the server with auth
enabled. Complements the `DQT_DASHBOARD_TOKEN` env var. Flags are mutually
exclusive. Using `--token` on shared systems is discouraged; prefer the env var.

### Parametrized CLI smoke tests
`packages/dqt/tests/cli/test_cli_smoke.py` covers every registered subcommand:
`--help` exits 0, expected flags present, top-level help lists the subcommand,
missing required args produce a clean error (no traceback).

### `scripts/update_readme_numbers.py`
Reads detector count from the registry and adapter count from the catalog.
Updates the `<!-- NUMBERS_START -->...<!-- NUMBERS_END -->` block in README.md.
Call before tagging a release.

### `list-detectors --group` / `--verbose`
Filter by group; verbose mode adds kind and min_n columns (if not already
present from v0.8.0).

## Breaking changes

None.

# dqt v0.8.5 -- Release Notes

## Summary

Property-based tests for ProofBundle and LineageGraph, plus a GitHub Actions
reusable workflow.

- `packages/dqt/tests/test_proof_property.py` -- 5 Hypothesis properties for compute_proof/verify_proof

- `.github/workflows/dqt-check.yml` -- reusable workflow: install dqtlib, run checks, post JUnit results

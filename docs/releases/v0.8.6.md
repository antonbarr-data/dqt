# dqt v0.8.6 -- Release Notes

_Released: 2026-05-12_

## Summary

Prometheus metrics exporter. `dqt prometheus-exporter` serves `/metrics` with
gauges for check scores, verdicts, and run counts. Pure-Python implementation
requires no runtime dependencies.

## What's new

- `dqt.metrics.prometheus.build_metrics_text(store)` -- Prometheus text-format metrics
- `dqt prometheus-exporter --port 9100` -- CLI command serving /metrics
- Metrics: `dqt_check_score`, `dqt_check_verdict`, `dqt_check_runs_total`

## Breaking changes

None.

# airflow-providers-dqt v0.7.2 — Release Notes

_Released: 2026-05-12_

## Summary

`airflow-providers-dqt` — Apache Airflow provider with `DqtCheckOperator` and
`DqtSuiteOperator`. Both operators fail the Airflow task when dqt checks breach
the fail threshold, integrating cleanly with Airflow's retry and alerting machinery.

## Install

```bash
pip install airflow-providers-dqt
```

## What's new

### `DqtCheckOperator` — run a single check

```python
from dqt_airflow import DqtCheckOperator

check_orders = DqtCheckOperator(
    task_id="dqt_check_orders",
    check_factory=lambda: orders_completeness_check,
    runner_factory=lambda: build_runner(),
    adapter_factory=lambda: build_adapter(),
    fail_on_warn=False,     # True to also fail on warn verdict
)
```

Factories are called lazily at task execution time — no heavy objects in the DAG
module scope.

### `DqtSuiteOperator` — run a full suite

```python
from dqt_airflow import DqtSuiteOperator

run_all_checks = DqtSuiteOperator(
    task_id="dqt_suite",
    checks_factory=lambda: ALL_CHECKS,
    runner_factory=lambda: build_runner(),
    adapter_factory=lambda: build_adapter(),
    cost_budget_usd=10.0,
)
```

### Provider registration

The package registers with Airflow's provider system via the
`apache_airflow_provider` entry point — shows up in the Airflow Providers page.

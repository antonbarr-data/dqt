# dqt v0.5.4 — Release Notes

_Released: 2026-05-12_

## Summary

Continuous threshold calibration from stored run history. A new
`calibrate_from_history()` function analyses the empirical score distribution of
pass-verdict runs and signals when the configured warn threshold has drifted more than
10% from what the data actually warrants. Server schedulers and the CLI can call it
weekly to keep thresholds current without manual tuning.

## What's new

### `ThresholdDriftResult`

New dataclass exported from the top-level `dqt` namespace:

```python
@dataclass
class ThresholdDriftResult:
    check_id: str
    detector_slug: str
    n_pass_runs: int
    current_threshold: float    # active warn threshold (check override or STAT_SCALES default)
    suggested_threshold: float  # empirical (1 - target_fpr) percentile of pass scores
    drift_fraction: float       # |suggested - current| / current
    is_significant: bool        # drift_fraction > 0.10
```

### `calibrate_from_history(check, store, *, target_fpr, min_samples, drift_threshold)`

```python
result = dqt.calibrate_from_history(check, store)
if result and result.is_significant:
    print(f"Threshold drift {result.drift_fraction:.0%} — suggest {result.suggested_threshold:.4f}")
```

Returns `None` when the store holds fewer than `min_samples` (default 50) pass-verdict
runs — not enough history to calibrate reliably.

**Algorithm:**
1. Load all `RunResult` records for `check` from `store`.
2. Keep only `Verdict.pass_` records (ignores warn/fail runs).
3. Compute the `(1 - target_fpr) * 100`th percentile of their scores as the suggested threshold.
4. Compare to the active warn threshold (`check.warn_threshold` if set, else `STAT_SCALES` default).
5. If `|suggested - current| / current > drift_threshold` (default 10%) set `is_significant=True`.

**Scheduling:** The library does not schedule this call — that is a server concern. The
recommended cadence is weekly, or after any batch of HITL reviews marks new passes.

**Parameters:**

| Parameter | Default | Description |
|---|---|---|
| `target_fpr` | `0.001` | Desired false-positive rate at the suggested threshold |
| `min_samples` | `50` | Minimum pass runs required to return a result |
| `drift_threshold` | `0.10` | Relative drift that sets `is_significant` |

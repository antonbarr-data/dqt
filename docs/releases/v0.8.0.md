# dqt v0.8.0 — Release Notes

_Released: 2026-05-12_

## Summary

Provable correctness for declarative checks. `ProofBundle` cryptographically
binds a `RunResult` to the sample data it was computed from. Anyone with the
sample can re-derive the data hash and verify the commitment -- proving that a
given verdict was produced from specific data by a specific algorithm version,
without re-running the check.

## What's new

### `ProofBundle` -- cryptographic proof artifact

```python
from dqt import compute_proof, verify_proof

# After running a check
run_result = runner.run(check, adapter)

# Bind the result to the sample it was scored on
proof = compute_proof(run_result, sample_df)
print(proof.commitment)   # 64-char SHA-256 hex digest
print(proof.data_hash)    # SHA-256 of the row-sorted sample
print(proof.row_count)    # number of rows sampled

# Later, verify nothing was tampered with
ok = verify_proof(proof, run_result, sample_df)
assert ok  # True iff data, verdict, and score are all consistent
```

### Commitment algorithm

SHA-256 of a canonical JSON encoding of:

```
(run_id, check_id, detector_slug, detector_version, data_hash, verdict, score)
```

`sort_keys=True`, compact separators, score rounded to 10 decimal places to
avoid float serialisation variance.

### Data hash

SHA-256 of the row-sorted, tab-separated sample. Columns are sorted
alphabetically before serialisation -- the hash is independent of column order
and row fetch order.

### `proof.to_dict()`

Returns a plain `dict` suitable for JSON storage alongside the run result:

```python
{
  "run_id": "...",
  "check_id": "...",
  "detector_slug": "ks_2sample",
  "detector_version": "1",
  "data_hash": "abc123...",
  "row_count": 100000,
  "commitment": "def456...",
  "commitment_algorithm": "sha256",
  "computed_at": "2026-05-12T10:00:00+00:00"
}
```

### `verify_proof(proof, run_result, sample_df) -> bool`

Re-derives data hash and commitment from the provided inputs. Returns `True`
only when both match the stored proof and row counts agree.

## Module

`dqt.store.proof` -- importable directly or via the top-level `dqt` namespace:

```python
from dqt import ProofBundle, compute_proof, verify_proof
from dqt.store.proof import ProofBundle, compute_proof, verify_proof  # equivalent
```

## Tests

`packages/dqt/tests/test_proof.py` -- 15 tests covering:
- Data hash stability (row-order and column-order independence)
- Commitment determinism
- Proof verification for valid proofs
- Tamper detection (data, score, verdict, commitment field)

## Breaking changes

None.

# dqt v0.8.7 -- Release Notes

_Released: 2026-05-12_

## Summary

Algorithm correctness and usability improvements across 6 detectors.

## What's new

- **STL auto-period** (`period=None`): dominant frequency detection via FFT; fallback 7
- **Prophet NaN handling**: missing days in current data no longer crash scoring
- **Cramers V bias correction**: Bergsma-Wicher corrected formula; version bumped to 2
- **LOF auto-k**: `n_neighbors=None` uses `max(5, ceil(sqrt(n)))`; k exposed in details
- **Mahalanobis singular covariance**: `singular_covariance` surfaced in details when pinv fallback used
- **Auto-outlier router logging**: `chosen_detector` surfaced in details
- **Schema rename detection**: fuzzy column matching (Levenshtein <= 2, same dtype) emits `renamed_columns`

## Breaking changes

- `CramersVDetector.version` bumped from "1" to "2" -- existing baselines will be auto-refit by the runner

# dqt v0.5.3 — Release Notes

_Released: 2026-05-12_

## Summary

Detector versioning in `RunResult`. Every detector now carries a `version` class attribute.
The runner stamps it on every stored result and automatically re-fits stale baselines when
the algorithm version changes — no manual intervention needed.

## What's new

### `BaseDetector.version: ClassVar[str] = "1"`

Every detector inherits a `version` class attribute. When the scoring algorithm changes
in a meaningful way (changed formula, new parameters, bug fix that shifts scores), bump
this string. The runner uses it to detect cached baselines that were fit with an older
algorithm.

To bump a detector's version:

```python
class MyDetector(BaseDetector):
    slug = "my_detector"
    version = "2"   # was "1" — bumped after scoring formula change
```

### `RunResult.detector_version: str = "1"`

Every stored result now carries the detector version that produced it. Defaults to `"1"`
for backwards compatibility with results written before this release.

The field is included in `to_bundle()` output (`result.json`), so offline reproduction
bundles are self-describing about which algorithm version ran.

### Runner auto-refit on version change

When `Runner.run()` is called and the in-memory cached state was fit with a different
detector version than the current one, the runner:

1. Logs a `detector_version_changed_refitting` warning at WARNING level
2. Calls `fit()` again using the current algorithm
3. Continues with the fresh state

This is fully transparent: existing callers get correct results without any code changes.

```
[WARNING] detector_version_changed_refitting check_id=... slug=zscore_outlier_fraction
          cached_version=1 current_version=2
```

## Tests

`packages/dqt/tests/test_detector_versioning.py` — 8 new tests:

| Test | What it covers |
|---|---|
| `test_base_detector_has_version` | `completeness` exposes `version` attribute |
| `test_all_registered_detectors_have_version` | All 64 detectors have `version` |
| `test_run_result_has_detector_version` | RunResult carries non-empty version |
| `test_run_result_detector_version_matches_cls` | Stamped version matches `cls.version` |
| `test_runner_refits_when_version_changes` | Re-fit triggered on version mismatch |
| `test_run_result_detector_version_after_refit` | Post-refit result carries new version |
| `test_to_bundle_includes_detector_version` | `result.json` includes `detector_version` |
| `test_default_run_result_detector_version` | Old `RunResult` without field defaults to "1" |

## Breaking changes

None. `RunResult.detector_version` has a default value of `"1"` so existing call sites
that construct `RunResult` directly are unaffected.

## Upgrade

```bash
pip install --upgrade dqtlib
```

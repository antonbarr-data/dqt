# dqt v0.8.2 -- Release Notes

_Released: 2026-05-12_

## Summary

Failure-mode documentation for all 64 detectors. Every detector page now
includes: a failure-mode table (symptom + fix), FPR at defaults by data shape,
recommended thresholds by data shape. Modelled after the ADWIN docs.

## What's new

Failure-mode sections added to all detector docs in `docs/algorithms/`:
- outliers_uni: mad, double_mad, zscore, iqr_fence, adjusted_boxplot, grubbs, gesd, auto_outlier
- drift: ks_pvalue, wasserstein_1, psi, kl_divergence, js_divergence, mmd, chi_square_drift
- timeseries: stl, cusum, page_hinkley, holt_winters, matrix_profile, prophet_anomaly, bocpd
- outliers_multi: isolation_forest, mahalanobis, lof, one_class_svm, hbos, ecod
- pattern: benford_law_fit
- basic/schema/referential: null_fraction, completeness, uniqueness, value_in_range, set_membership,
  schema_change, referential_integrity_rate, freshness_seconds_behind

## Breaking changes

None.

# v0.8.9 - 2026-05-13

## Prometheus exporter fix

- **Fix:** `build_metrics_text` now iterates over all check runs keyed by `check_id`,
  not just checks that have fired an incident. Always-passing checks now appear in
  `/metrics` with `dqt_check_verdict 0`.
  (Note: for stores without an in-process `_runs` dict, e.g. future PostgresStore
  callers, a `list_check_ids()` protocol method will be needed.)
- **Fix:** `dqt_check_runs_total` type corrected from `gauge` to `counter`.

## Verified working

- `dqt wiki sync` / `dqt wiki status` - confirmed accessible via `dqt wiki --help`
- Dashboard bearer auth (`DQT_DASHBOARD_TOKEN` + `Authorization: Bearer <token>`) -
  confirmed by existing auth tests in `packages/dqt/tests/dashboard/test_dashboard_auth.py`

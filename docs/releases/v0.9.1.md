# v0.9.1 - 2026-05-13

## Bug fixes

- **Prometheus exporter (protocol fix):** `build_metrics_text` now uses
  `store.list_check_ids()` via the `ResultsStore` protocol instead of
  accessing `store._runs` directly. Both `MemoryStore` and `PostgresStore`
  implement `list_check_ids()`. PostgresStore users now get correct `/metrics`
  output instead of an empty endpoint.

- **`dqt wiki sync` / `dqt wiki status` CLI subcommands:** Added to the
  in-wheel argparse CLI (`dqt.cli.main`). Calls the existing `dqt.wiki`
  module (shipped since v0.4.8). Flags: `raw_dir`, `wiki_dir`, `--model`,
  `--force`.

- **`dqt dashboard --token` / `--generate-token`:** Added to the in-wheel
  dashboard subcommand. Sets `DQT_DASHBOARD_TOKEN` env var before starting
  uvicorn. Mutual exclusion enforced.

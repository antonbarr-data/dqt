# dbt-dqt v0.7.1 — Release Notes

_Released: 2026-05-12_

## Summary

`dbt-dqt` — run dqt quality checks for models that completed successfully in a dbt run.
Reads `target/run_results.json` to identify successful models, then runs the matching
checks via `Runner.run_suite()`.

## Install

```bash
pip install dbt-dqt
```

## What's new

### `run_checks_for_dbt_run(runner, adapter, checks, run_results_path, cost_budget_usd)`

```python
from dbt_dqt import run_checks_for_dbt_run

result = run_checks_for_dbt_run(
    runner=runner,
    adapter=adapter,
    checks=all_checks,
    run_results_path="target/run_results.json",  # default
    cost_budget_usd=10.0,
)
print(f"Ran {len(result.suite.ran)}, matched {len(result.matched_checks)} dbt models")
```

### `DbtRunResult` dataclass

```python
@dataclass
class DbtRunResult:
    suite: SuiteResult              # from Runner.run_suite()
    dbt_success_models: list[str]   # model names from run_results.json
    matched_checks: list[Check]     # checks that ran (table_name in success models)
    unmatched_checks: list[Check]   # checks skipped (model not in this dbt run)
```

### `run_all_on_missing_results` flag

If `run_results.json` does not exist (e.g., running in a CI pipeline without dbt),
pass `run_all_on_missing_results=True` to run all checks anyway.

# dqt v0.4.9 — Release Notes

_Released: 2026-05-12_

## Summary

The trust-building batch: verifiable docs coverage, generalised CLI smoke tests, and
public detector benchmarks. Every capability claim is now independently verifiable.

## What's new

### Tests

- **Docs completeness gate** (`packages/dqt/tests/docs/test_docs_completeness.py`) —
  three parametrised tests that permanently lock in doc/code alignment:
  - `test_every_slug_has_a_doc` — every registered detector slug must have
    `docs/algorithms/<slug>.md`; fails at import-time if a new detector ships without docs.
  - `test_no_stale_docs` — every doc file must map to a registered slug; catches renames.
  - `test_doc_has_required_sections[<slug>]` (64 parametrised cases) — every detector doc
    must contain `## When it works well`, `## When it fails`, and
    `## Recommended thresholds`. Currently 66/66 passing.

- **Generalised CLI smoke tests** — `packages/dqt-cli/tests/test_smoke.py` now opens with
  a `_HELP_CASES` list: one entry per subcommand path, checked via a single parametrised
  `test_help_exits_cleanly` test. Adding a new command is one list append; forgetting it
  causes a gap that reviewers can see at a glance. Covers all 12 command paths: `--help`,
  `version`, `run`, `dashboard`, `list-detectors`, `demo seed`, `demo reset`,
  `wiki`, `wiki sync`, `wiki status`, `report`. Total: 33 tests, 33 passing.

### Benchmarks

- **`examples/benchmarks/results.csv`** — machine-readable benchmark results for all
  scored detectors: slug, TP, FP, FN, TN, precision, recall, F1, FPR. Auto-generated by
  `benchmarks/run_benchmarks.py`. Every quality claim is now user-verifiable.

- **README benchmark table** — inline precision/recall/F1/FPR table for the 17 scored
  detectors, with links to the full `docs/benchmarks.md` and raw CSV.

- **`docs/benchmarks.md`** updated with link to the CSV.

### Benchmark methodology upgrade (post-release patch)

The original single-run benchmark was replaced with a statistically rigorous suite
following expert review:

- **30 independent trials** (seeds 0-29) -- reports mean, std, and 95% CI per detector
  instead of single-point estimates.
- **N=2,000 per fixture** (up from 500) -- stable confusion matrix counts.
- **8 fixture scenarios** (up from 4) -- added variance explosion, gradual ramp drift,
  combined drift+nulls, and heavy-tail contamination to represent realistic production
  failure modes.
- **Detector families** -- output split into Outlier / Distribution Drift / Time-Series /
  Distribution Diagnostic sections so comparisons are within-family only.
- **4 baseline models** -- `_always_alert` (F1=0.667), `_never_alert` (F1=0), `_random_50pct`
  (F1~0.49), `_naive_zscore` (F1~0.14) give concrete reference points for every table.
- **CSV schema extended** -- `f1_mean`, `f1_std`, `f1_ci_lo`, `f1_ci_hi`, `recall_std` now
  included alongside the original point-estimate columns.

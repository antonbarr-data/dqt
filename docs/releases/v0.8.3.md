# dqt v0.8.3 - Release Notes

_Released: 2026-05-12_

## Summary

`PostgresStore` - persistent `ResultsStore` backed by PostgreSQL. Replaces
`MemoryStore` for production deployments where data must survive restarts.
Also ships `save_proof()`/`list_proofs()` on all store implementations, and
`query_runs()` filtered query API on both stores.

## What's new

### `PostgresStore`

```python
from dqt import PostgresStore
store = PostgresStore("postgresql://user:pass@host:5432/mydb")
```

Creates the schema on first use (`dqt_runs`, `dqt_incidents`, `dqt_proofs`,
`dqt_causal_reviews`). Idempotent DDL. Uses `psycopg2` (install `dqtlib[postgres]`).

### `store.save_proof()` / `store.list_proofs(check_id)`

Both `MemoryStore` and `PostgresStore` now persist `ProofBundle` objects.

### `store.query_runs(check_id, verdict, since, until, limit)`

Filtered query across runs on both `MemoryStore` and `PostgresStore`.

## Breaking changes

`ResultsStore` protocol now requires `save_proof`, `list_proofs`, and `query_runs`.

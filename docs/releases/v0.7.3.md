# dagster-dqt v0.7.3 — Release Notes

_Released: 2026-05-12_

## Summary

`dagster-dqt` — Dagster resource and helper for running dqt quality checks as part
of an asset materialization pipeline. `DqtResource` holds the Runner and adapter;
`run_dqt_checks()` runs a suite and raises `DqtAssetCheckFailed` on any failure so
Dagster marks the step as failed.

## Install

```bash
pip install dagster-dqt
```

## What's new

### `DqtResource` — configurable Dagster resource

```python
from dagster import Definitions, asset
from dqt_dagster import DqtResource

@asset
def orders(dqt_resource: DqtResource):
    # ... your asset materialisation logic
    dqt_resource.run_checks_for(table="orders")   # fails asset on dqt failure

defs = Definitions(
    assets=[orders],
    resources={
        "dqt_resource": DqtResource(
            runner_factory=build_runner,
            adapter_factory=build_adapter,
            checks=ALL_CHECKS,
            cost_budget_usd=5.0,
        )
    },
)
```

### `DqtResource.run_checks_for(table)`

Filters checks to those matching `table_name == table`, runs them, and raises
`DqtAssetCheckFailed` if any verdict is fail.

### `DqtResource.run_suite(checks, cost_budget_usd)`

Runs an explicit list of checks (or all resource checks if `checks=None`).

### `run_dqt_checks(checks, runner, adapter, cost_budget_usd, fail_on_warn)`

Standalone helper for use outside the resource pattern. Raises `DqtAssetCheckFailed`
on any failing check.

### `DqtAssetCheckFailed`

Subclass of `Exception`. Dagster surfaces this as a step failure with the full
check details in the error message.

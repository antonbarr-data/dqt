# dqt v0.7.0 — Release Notes

_Released: 2026-05-12_

## Summary

Native Slack/Teams bot handler — `/dq check`, `/dq incidents`, `/dq why` slash commands
with zero server dependency. Takes a `Runner`, `ResultsStore`, and optionally a
`LineageGraph` as constructor args and works entirely in-process. Formatters produce
Slack block-kit JSON and Teams Adaptive Card JSON from the same `BotResponse`.

## What's new

### `DqtBotHandler` — `dqt.bot`

```python
from dqt import DqtBotHandler, BotCommand

handler = DqtBotHandler(
    store=results_store,
    checks=all_checks,
    graph=lineage_graph,          # optional — enables /dq why
)

# In your Slack webhook handler:
command = BotCommand.parse(request.form["text"], user_id=..., workspace_id=...)
response = handler.handle(command)
return jsonify({"blocks": response.blocks})
```

### Slash commands

| Command | Description |
|---|---|
| `/dq check <table>` | Most recent run result for every check on `<table>` |
| `/dq incidents [--fail]` | List open incidents; `--fail` shows only severity=fail |
| `/dq why <table> [<column>]` | Granger-based causal explanation for the latest failing incident |

### `BotCommand.parse(text)`

Parses the raw slash command text into a `BotCommand` dataclass:

```python
cmd = BotCommand.parse("check orders")
# BotCommand(name='check', args=['orders'])
```

### `BotResponse` dataclass

```python
@dataclass
class BotResponse:
    text: str                        # plain-text fallback
    blocks: list[dict]               # Slack block-kit JSON
    card: dict                       # Teams adaptive card JSON (populated by to_teams_card)
```

### `to_slack_blocks(response)` / `to_teams_card(response)`

Platform formatters. `to_slack_blocks` returns the blocks list directly. `to_teams_card`
wraps blocks in a version 1.4 Adaptive Card body:

```python
from dqt import to_slack_blocks, to_teams_card

# Slack
return {"blocks": to_slack_blocks(response)}

# Teams
return to_teams_card(response)
```

### Integration patterns

**AWS Lambda + Slack:**
```python
import json, dqt

handler = dqt.DqtBotHandler(store=store, checks=checks)

def lambda_handler(event, _ctx):
    body = json.loads(event["body"])
    cmd = dqt.BotCommand.parse(body.get("text", ""))
    resp = handler.handle(cmd)
    return {"statusCode": 200, "body": json.dumps({"blocks": resp.blocks})}
```

**FastAPI + Teams:**
```python
from fastapi import FastAPI, Request
from dqt import DqtBotHandler, BotCommand, to_teams_card

app = FastAPI()
bot = DqtBotHandler(store=store, checks=checks)

@app.post("/teams/webhook")
async def teams_hook(req: Request):
    data = await req.json()
    cmd = BotCommand.parse(data.get("text", ""))
    resp = bot.handle(cmd)
    return to_teams_card(resp)
```

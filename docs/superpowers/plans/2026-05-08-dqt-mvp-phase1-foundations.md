# dqt MVP — Phase 1: Repo Foundations

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap the monorepo so `make install` works, Docker services start, and all four Python packages are importable — giving every subsequent phase a solid foundation to build on.

**Architecture:** uv workspace managing four Python packages (dqt, dqt-cli, dqt-server, dqt-worker); pnpm managing apps/web (Next.js 14). Shared JSON enums in shared/config/. Docker Compose for Postgres + Redis + MailHog + Adminer.

**Tech Stack:** Python 3.12, uv, hatchling, pnpm 9, Next.js 14, Tailwind 3, shadcn/ui, Docker Compose.

**Spec reference:** `docs/superpowers/specs/2026-05-08-dqt-mvp-design.md` sections 2–5.

**Subsequent phases:**
- Phase 2: `packages/dqt` library (adapters, algorithms, checks, store, runner)
- Phase 3: DB schema + `apps/server` (auth, CRUD, WebSocket)
- Phase 4: `apps/web` (AppShell + 4 screens)
- Phase 5: `apps/worker` + `packages/dqt-cli` + demo seed

**Acceptance criteria (end of this phase):**
- `uv sync` completes without errors
- `python -c "import dqt; print(dqt.__version__)"` prints `0.1.0`
- `./run_local/start.sh` starts all four Docker services healthy
- `cd apps/web && pnpm build` succeeds
- `make lint` passes (ruff, mypy on stubs, eslint, tsc)

```bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"

echo "Starting dqt local stack..."

docker compose -f "${SCRIPT_DIR}/docker-compose.yml" up -d

echo -n "Waiting for Postgres..."
until docker compose -f "${SCRIPT_DIR}/docker-compose.yml" exec -T postgres \
  pg_isready -U dqt -d dqt > /dev/null 2>&1; do
  echo -n "."
  sleep 1
done
echo " ready."

echo -n "Waiting for Redis..."
until docker compose -f "${SCRIPT_DIR}/docker-compose.yml" exec -T redis \
  redis-cli ping 2>/dev/null | grep -q PONG; do
  echo -n "."
  sleep 1
done
echo " ready."

echo ""
echo "Stack running:"
echo "  Postgres  → localhost:5434  (user: dqt, pass: dqtdev, db: dqt)"
echo "  Redis     → localhost:6379"
echo "  MailHog   → http://localhost:8025"
echo "  Adminer   → http://localhost:8081"
echo ""
echo "Next: make db-migrate && make dev-server && make dev-web"
```
